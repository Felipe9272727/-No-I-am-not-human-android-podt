# No, I'm not a Human — port Android experimental

Reconstrução em andamento a partir da versão 1.3.18 fornecida pelo usuário. Este repositório preserva o código novo, ferramentas de extração, evidências e testes para permitir retomar o trabalho após reinícios do ambiente.

A base validada combina regras C++, intérprete Yarn em Rust e apresentação Android Java/libGDX. Ela contém menu, vídeo de abertura com áudio e legendas, primeira visita do vizinho, primeira conversa dentro da casa e estado de telefone. A campanha completa ainda não está implementada; o save atual dura somente a execução do aplicativo.

O trabalho atual acrescenta a casa 3D original, joystick, câmera por toque e interface reconstruída com os recursos originais. Esses itens precisam de integração e validação gráfica antes de serem tratados como concluídos.

Os executáveis e DLLs de Windows, chaves de assinatura, caches, SDK/NDK e pacotes grandes não devem ser enviados ao Git. As ferramentas de extração trabalham sobre arquivos de dados e não executam os binários originais.

O código e as instruções de recuperação estão sendo importados em commits seguintes.
