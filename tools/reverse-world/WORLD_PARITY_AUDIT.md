# Level-1 world parity audit

The current manifest and renderer agree on the source camera and coordinate conversion. The source Main Camera is Camera PathID 2060 / Transform PathID 1935. Its world position is `(-3.985, 1.584, -6.998)`, FOV is 60 degrees, and clips are 0.1 / 1000 metres. Its transform is parented to PlayerCameraController Transform 1660, itself parented to PlayerInstance Transform 1541 at Y `-0.066`; the camera's local Y is `1.65`. Thus the port's 1.65 metre eye offset describes the source hierarchy, and the initial camera position is loaded from the source camera transform.

The nearby BlockingFloorQuad is renderer PathID 2072 and MeshCollider PathID 2394 at Y `-0.186021`. Its top surface is about 12 cm below the initial camera's inferred feet position. The existing movement code can settle the player onto that source collider when movement begins. This is not evidence for an initial spawn correction, so no guessed offset was applied.

The exporter writes unconverted Unity coordinates and composes local TRS through each parent. The renderer reflects mesh vertex and normal Z, reverses each triangle's winding, and conjugates source matrices by the Z reflection. Its bounds calculation applies the same conversion. Active-in-hierarchy renderers are selected from the exporter flag; there are 109 active renderers among 153 source MeshRenderers. All exported parent transform references resolve.

Run `python tools/reverse-world/audit_world_parity.py --data /path/to/unity-data` from the repository root for the raw-source audit. `--data` can be the Unity data directory containing `level1` or the `level1` file itself. The audit reads serialized Unity objects with UnityPy, independently composes local TRS through parent transforms, computes active-in-hierarchy from GameObject active flags, and compares all transform rows and all 153 MeshRenderer references, enabled/active flags, and matrices to the staged manifest. It reports the raw `level1` SHA-256, counts, and maximum absolute matrix/local-TRS error. In the restored source snapshot the audit checked 1,348 transforms and 153 renderers, with maximum error zero. Without `--data`, it explicitly reports that the raw-source audit was skipped and runs only manifest-consistency checks. The source extraction itself remains static and does not execute original binaries.
