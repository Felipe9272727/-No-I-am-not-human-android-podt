Run `python tools/reverse-world/audit_world_parity.py --data /path/to/unity-data --manifest /path/to/world_manifest.json` from the repository root for the raw-source audit. `--data` can be the Unity data directory containing `level1` or the `level1` file itself; `--manifest` defaults to the Android staged manifest. The audit reads serialized Unity objects with UnityPy, independently composes local TRS through parent transforms, computes active-in-hierarchy from GameObject active flags, and compares all transform rows, MeshRenderer references and matrices, and SkinnedMeshRenderer references, active flags, materials, and matrices. In a fresh source export the audit checked 1,348 transforms, 153 MeshRenderers, and six SkinnedMeshRenderers; maximum matrix/TRS error was zero. Without `--data`, it reports that the raw-source audit was skipped and runs manifest-consistency checks. The source extraction remains static and does not execute original binaries.
