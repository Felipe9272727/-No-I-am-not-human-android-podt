# Static security review — No, I'm not a Human v1.3.18

## Scope and result

Reviewed the supplied ZIP and its extracted tree by static inspection only. No EXE, DLL, MSI, game process, installer, or bundled script was executed. The ZIP contains 108 entries (93 files and 15 directories); every file entry was streamed and its CRC32 and uncompressed SHA-256 recorded. The existing extracted review tree contains 99 files; every file has a SHA-256 and `file(1)` magic identification in `file-manifest.csv`. Of these, 93 correspond to ZIP files and six hidden/temp-named Unity/PDF fragments are extra files in the review tree that do not occur as entries in the supplied ZIP. These six are inventory-only and are not treated as malware evidence. Entry-level hashes and sizes are in `zip-entry-manifest.csv`.

The evidence does not establish that the package is malware-free. The scan did not have a usable current AV signature database. Prior public reports and signature checks are described in the handoff notes below; reputation results are mixed. There is no confirmed malware payload from this static review, but one key Steam DLL is modified and fails its embedded Authenticode digest check, so treat the package as untrusted.

## Main findings

- Direct `MZ` plus `PE\0\0` header checks identify 16 PE/Windows executables or DLLs (9 `.exe`, 6 `.dll`, and the disguised `.rne`), including `NoImNotAHuman.exe`, `GameAssembly.dll`, `UnityPlayer.dll`, `baselib.dll`, `UnityCrashHandler64.exe`, D3D12, Burst, Steamworks, and eight redist installers. The disguised `steam_api64.rne` is also a PE32+ x86-64 DLL, not data. These must never be included in an Android native reconstruction build.
- `steam_api64.dll` (1,098,392 bytes) has a signature block but its Authenticode digest does not match the file; prior triage identified it as packed and likely modified/cracked. SHA-256: `f480de9ae15e17fb6e84ad0efa8a386095700cfb7f405bfd64aa61d518587b79`. Do not reuse it.
- `steam_api64.rne` (300,392 bytes) has an Authenticode signature verified with osslsigncode and is still a Windows DLL unnecessary for Android. Unity runtime binaries were previously signature-verified. Redist signature digests matched, but the trust chain could not be fully verified. A valid signature establishes publisher integrity for the signed bytes, not benign runtime behavior.
- The root `.url` shortcut opens `https://steamunlocked.org/`. This is the only plainly promotional/external link found in the packaged text files. Do not carry it into the app.
- The ordinary artbook in the ZIP (195,477,185 bytes) is parsed by `pdfinfo` as 26 pages and reports no JavaScript; `pdfinfo` identifies the producer as Pdftools SDK. A hidden 70,778,880-byte `.pdf.ykYK9H` file in the review extraction tree begins like the artbook but has a malformed/truncated cross-reference/trailer and cannot be parsed; that filename is absent from the supplied ZIP. Its malformed state and raw `/JS`/`/AA` byte matches inside compressed/binary stream data are not evidence of malware. Exclude the extraction-only fragment. Include the ordinary artbook only if needed and after a safer document validation/rendering pass.
- No standalone `.js`, `.vbs`, `.ps1`, `.bat`, `.cmd`, `.sh`, `.hta`, or `.lnk` scripts were present. The text/config inventory includes the run instructions, Steamworks note, Steam emulator INI, Unity JSON/XML configs, and the URL shortcut. No obvious shell/PowerShell launch commands were found.
- Embedded URLs extracted from PE resources are mostly Microsoft, DigiCert, and VeriSign certificate/CRL/OCSP or license endpoints, plus standard Unity analytics/performance endpoints (`cdp.cloud.unity3d.com`, `perf-events.cloud.unity3d.com`) and curl documentation links. These strings are consistent with bundled signed components and do not by themselves indicate C2. The game addressables config points to a local catalog and contains no remote catalog URL.
- Unity assets, resource files, bundles, and `GameAssembly.dll` are proprietary serialized content/code. Their file types alone cannot establish that their contents are benign. The ZIP contains no nested archive identified in the extracted tree; installer containers include self-extracting redistributables and an MSI, none inspected by execution.

## Reconstruction allowlist guidance

For a clean native Android reconstruction, use only the source art/audio/text/gameplay data needed and validated from the Unity asset/resource content. Re-export assets into standard formats and include those exported data files. Do not copy any Windows PE, redist installer/MSI, Steam emulator DLL/config, `.url` shortcut, hidden malformed PDF, or Unity executable/runtime into the Android package. Avoid copying raw Addressables/serialized bundles unless their contents have been separately inspected and the Android build pipeline explicitly needs them. Treat all upstream assets as untrusted input to parsers.

## Limits

This is a static triage, not a sandbox detonation or complete reverse engineering of the 81.6 MB IL2CPP assembly and asset corpus. The ClamAV binary was available but no current virus database could be obtained: privilege-switching failed, official CVD download returned 403, and cvdupdate DNS resolution failed. These routes were attempted once and not retried. Previously observed public scanning had mixed generic detections (2/70), a hybrid malicious header despite 0/27 AV detections, and no specific threat in one sandbox. Those scores are inconclusive and should not be read as a clean bill of health.
