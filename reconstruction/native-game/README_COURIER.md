# Courier and deficit service recovery

`CourierService` reproduces the Yarn wrapper behavior while keeping Unity-owned state outside the native class. `DayNightCourierRefs` reads the current day and saved last-courier day from the existing day/night state. `ConsumablesDeficitService` reads the existing inventory, the original `OtherGameSOData` deficit map and random-days getter, and the existing `ConsumablesSaveData.DeficitItemDay` field by reference. Dialog callbacks preserve delegate registration order and let the existing save-data handler consume and clear the courier order.

`CanOrderCourier` follows `DayNightController.OnCouldOrderCourier`: it returns `lastCourierOrderedDay + 2 < currentDay`. There is no time-of-day or energy-action check in that method. `OrderCourier` parses `EConsumable` names case-insensitively, then invokes ordered subscribers in registration order. It passes `count` through unchanged and does not call `CanOrderCourier` or charge inventory. `Enum.Parse` also accepts numeric enum values, including values not named in the enum. The enum table and field layout are in `../logic/cpp2il_cs/DiffableCs/Assembly-CSharp/_Code/Infrastructure/Consumables/EConsumable.cs` and the recovered ISIL listed in `../reverse-services/courier.md`.

`GetCourierOrder` invokes the configured `GotCourierOrder` callbacks in order and uses the last callback result, matching CLR multicast `Func` semantics. The source `DialogManager.OnGotCourierOrder` copies and clears `DialogSaveData.CourierOrderData`, adds that item/count to `IConsumablesController` with its hint flag set, and returns it. If the callback is absent or returns null, the wrapper formats the fallback `Bobeer × 1`; that fallback does not add inventory. Display text uses localization key `consumable_<lowercase enum name>_name` from the `UI` table and the suffix `(x<count>)`. The native service requires a localization callback and reports an explicit unsupported error when none is wired.

The deficit logic uses the source `ConsumablesSaveData.DeficitItemDay` value directly. `IsNeedToGetDeficitItem` is false while `currentDay < DeficitItemDay`; from that day onward it is true when any configured target satisfies `targetCount >= current inventory count` (inclusive comparison recovered from the generated predicate). `PeekDeficitItem` calls the controller's random selection and returns `EConsumable.ToString()`; it does not remove or add an item. The random selector receives candidates in original dictionary enumeration order and calls the injected Unity-range hook with `(0, candidateCount)`. With no eligible candidate, the source random-element helper returns default `EConsumable` (Bobeer). `UpdateDeficitDay` sets the existing `DeficitItemDay` field to `currentDay + OtherGameSOData.GetDeficitRandomDaysCount`; the getter's configured bounds and Unity RNG remain caller-owned.

The serialized `OtherGameData` object is path ID 2715 in `sharedassets0.assets`. Static parsing of its schema and raw bytes recovered days range `(2, 3)` and the ordered deficit targets `Enerjeka: 2`, `Cigarette: 0`, `Coffee: 1`, `CatFood: 0`, `Kombucha: 1`, and `Povistka: 0`. These values are recorded in `../reverse-services/courier.md`; the runtime code accepts the source typed values through `OtherGameDeficitDataRef` instead of hard-coding a second copy.

No courier price, payment, or item quantity generation exists in the recovered `OrderCourier` wrapper: Yarn supplies the item and count. The exact callback implementations for saving an order, applying the delivery, and updating day/night save state are explicit hooks for root integration. Missing event subscribers follow the wrapper defaults: `CanOrderCourier` false, `OrderCourier`/`UpdateDeficitDay` no-op, `IsNeedToGetDeficitItem` false, and `PeekDeficitItem` empty. If `GetCourierOrder` has no subscriber, it still returns the Bobeer × 1 display fallback.

Run the native regression set with `python3 tools/native-game/build_host.py`. Tests cover the strict two-day courier gate, raw enum parsing and count passthrough, multicast callback order, order fallback/localization key, inclusive deficit thresholds, original item order, random-selection injection, deficit-day update, and missing-subscriber defaults. No source executable or managed method was run.
