# Yarn binding inventory

`YARN_BINDINGS.json` is a reproducible static inventory generated by `python tools/native-game/audit_yarn_bindings.py`. It scans `reconstruction/narrative/program.json` for `RunCommand`, `CallFunc`, and `AddOption` instructions, joins game command/function names against `reconstruction/logic/yarn_api_map.md`, and checks whether each mapped game method has a heading in `reconstruction/logic/selected_method_bodies.il`.

The program has 3,255 nodes and 56,585 instructions: 4,043 command instructions, 2,821 function instructions, and 4,330 choices. The API map contains 50 commands and 19 functions. Of those 69 registered bindings, 60 occur in the program and 9 are unused. The program has 42 distinct command names (41 registered plus Yarn's built-in `wait`) and 30 function names (19 registered plus 11 Yarn standard functions: `Bool.*`, `Number.*`, `dice`, `visited`, and `visited_count`). The mapped commands account for 4,011 calls; `wait` accounts for 32. There are no used game API names missing from the map.

Selected method-body evidence covers 39 of the 60 used bindings by matching the mapped game method names to IL headings. The other 21 used bindings have no matching selected body listing; their API names and signatures remain evidenced by the map, but their behavior is not established by this inventory. Nine registered bindings do not appear in the narrative: `CallFEMATonight`, `FadeIn`, `FadeOut`, `KillNoGun`, `KillTomorrow`, `PerformEvent`, `PlayAnimation`, `RefuseOldLetInNew`, and `UnlockKillerEnding`.

Choice metadata tags are not present in the retained compiled narrative. All 3,255 node tag arrays are empty, while node headers (6,479 entries, primarily `title` and editor `position`) do survive. `AddOption` instructions carry the localized line ID, destination label, float, and boolean operands; there is no per-choice tag operand. The decoded program and the extracted raw MonoBehaviour string table expose compiled identifiers and bytecode operands, not the source Yarn metadata tags. Evidence is in `reconstruction/narrative/program.json`, `reconstruction/assets/narrative/compiled_yarn_program.json`, `reconstruction/assets/narrative/compiled_yarn_program.pb`, `reconstruction/assets/narrative/monobehaviour_2735.bin`, and `reconstruction/assets/narrative/monobehaviour_2735_strings.json`; extraction/schema handling is documented in `tools/assets/decode_yarn_program.py`.

This is a count and evidence-coverage report only. It does not infer command behavior from names or attempt to recreate missing source tags.

After the original archive was recovered, its separate Unity SharedTableData registry yielded the real per-line and per-choice tags. See `../reverse-localization/README.md` and `line_metadata.json`. The compiled Program still has empty node tags; this does not imply the original Unity localization metadata is missing.
