# Phone-number behavior evidence

This is static analysis from the `PhoneNumbersController` and `PhoneCloseUpView` IL/ISIL retained during the prior analysis session. The reset checkpoint currently retains the Cpp2IL C# declarations but does not contain the `reverse-events/cpp2il-isil` text files, so the key recovered branch observations are recorded here rather than claimed as a newly rerun disassembly.

`EPhoneSubscriber` values are declared in `reconstruction/logic/cpp2il_cs/DiffableCs/Assembly-CSharp/_Code/Infrastructure/CloseUps/Views/Phone/EPhoneSubscriber.cs`: `None=0`, then the 15 subscriber values through `DaughtersFriend=15`. `PhoneNumbersController` declares five `ENumberGeneratingType` values: `aaAaaA=0`, `AaaAaa=1`, `AaAOoO=2`, `AaaaaA=3`, `aAaaaA=4`.

The native `GeneratePhoneNumber` loop selects one of the five enum values by `RandomElementFromCollectionExtension.GetRandomElement`, then builds six digit characters. Native branches copy a prior character for pattern 0 position 5 from position 3; pattern 1 position 3 from position 0; pattern 2 position 2 from position 0; pattern 3 position 5 from position 0; and pattern 4 position 5 from position 1. Pattern 4 position 4 first draws a float in [0,1]; below 0.66 it draws an integer in [0,2), offsets position 1 by -1 for 0 or +1 for 1, and wraps modulo 10. Other positions use `Random.Range(0,10)`. The completed candidate is retried if any existing dictionary value equals it or if `Substring(0,3)` equals `Substring(3,3)`.

`GetNumberBySubscriber` calls `Dictionary.ContainsKey`; absent keys return the literal `000000`, otherwise it returns the stored string. `TryGetSubscriberByPhone` compares strings exactly, counts matches, sets the out enum to its default (`None`) and returns false when there are no matches, and uses `Enumerable.FirstOrDefault` to obtain the first matching dictionary entry when there is one or more. It does not use `Enum.Parse`.

`GenerateNumbers` iterates subscriber enum values excluding None, checks `OtherGameSOData._phoneNumbers`, inserts a configured number when present, and otherwise generates one. The native method uses `Dictionary.Add`; it throws on an existing key. The native host must call it on the same fresh/empty map conditions as the source caller; this model preserves the duplicate-key exception instead of silently replacing data.

Phone view call sites recorded from `PhoneCloseUpView`: `InitModules` initializes the controller and calls `GenerateNumbers`; `GetPhoneNumber` delegates to `GetNumberBySubscriber`; `UnlockPhoneSubscriber` appends the subscriber to the unlocked list, calls save-data `DistinctNumbers`, gets the assigned number, then creates a phone pin; `RestorePhoneNumbers` iterates saved subscribers and calls `GetNumberBySubscriber` before rebuilding pins. No name-to-enum parsing was observed in these methods.
