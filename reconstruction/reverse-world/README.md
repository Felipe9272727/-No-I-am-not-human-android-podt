# Original Unity level 1 world export

Static extraction from Unity `level1` using UnityPy 1.25.4; original EXE/DLL/installer is never executed. Reproduce with `python tools/reverse-world/export_world.py`. The exporter reads source `MeshHandler` vertices, normals, UV0, and triangle indices directly. It deliberately does not use UnityPy OBJ output, which changes X and reverses winding.

`world_manifest.json` carries source file/path IDs, all GameObject transforms, MeshRenderers and SkinnedMeshRenderers, materials, texture sampler settings, lights, render settings, colliders, cameras, start candidates, player, and six door targets. Active SkinnedMeshRenderers are baked at their serialized bone transforms with source weights and bind poses; the Animator is not evaluated. Inactive skinned components are listed with their original active flags and are not baked. Mesh binary records are interleaved little-endian float32 position3/normal3/UV0_2 (32 bytes) followed by little-endian uint32 indices. Source LH, Y-up, metre units and winding are retained; world matrices are row-major Unity TRS parent-compositions. A right-handed renderer must reflect positions/normals and triangle winding together.

The separately tracked `skinned_baseline.json` and `skinned_level1_f2_p310_renderer2558.bin` hold the one active source skinned pose used by the v12 asset staging path. Refresh them from a new static export with `python tools/android-current/stage_skinned_world.py --source-export /path/to/fresh/world_manifest.json`; run `python tools/android-current/stage_skinned_world.py` to stage the mesh and append its row while preserving the 100 original mesh rows. `prepare_assets.py` applies this staging step after its normal world mesh optimization. The staged baseline uses material source ref `level1:2/5` and texture ref `sharedassets1.assets:0/120`, which match v12 material 35 and texture 28.
