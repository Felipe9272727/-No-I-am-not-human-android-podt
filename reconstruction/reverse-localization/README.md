# Recovered Yarn line metadata

The real per-line and per-choice tags are in the original Unity Localization shared-data bundle, not in the compiled Yarn `Program` node tag arrays or English localized text rows. `SharedTableData.m_Entries` contains each `SharedTableEntry`'s key and `m_Metadata` collection; the collection points through Unity's `ManagedReferencesRegistry` to `Yarn.Unity.UnityLocalization.LineMetadata` objects in assembly `YarnSpinner.Unity`. Each such object stores `nodeName` and `tags`.

Run `python tools/reverse-localization/extract_line_metadata.py` to regenerate [`line_metadata.json`](line_metadata.json). The script loads just `localization-assets-shared_assets_all.bundle`, then validates every `RunLine` and `AddOption` first operand in `reconstruction/narrative/program.json` against its exact SharedTableData key and Yarn node. It does not load the game directory or execute the EXE/DLL.

Structural validation matched all 15,693 graph line IDs (11,363 spoken lines and 4,330 choices) to exactly one `LineMetadata` reference. There are no missing graph IDs, no node-name mismatches, and no duplicate or multi-node IDs. The shared table has 407 additional `line:` keys absent from the retained compiled graph; they remain in the JSON validation report as unused localization entries. All graph IDs have a metadata object, even when its `tags` array is empty.

Recovered tag totals across the graph are: `energy` 313, `day_dialog` 2, `get_item` 30, `give_item` 255, `gun` 357, `skip` 1, `rude` 10, and `lastline` 1,731. The tag sets are preserved as ordered arrays per exact line ID. `AddOption` choice entries contain all of `day_dialog` (1), `energy` (252), `get_item` (30), `give_item` (255), `gun` (357), `skip` (1), and `rude` (10); `RunLine` entries contain `day_dialog` (1), `energy` (61), and `lastline` (1,731). The JSON also records which compiled node and instruction kind uses each ID, plus the managed reference ID for traceability.

Source evidence: the extracted original bundle is `malware-review/No.Im.not.a.Human.v1.3.18/No.Im.not.a.Human.v1.3.18/NoImNotAHuman_Data/StreamingAssets/aa/StandaloneWindows64/localization-assets-shared_assets_all.bundle` (SHA-256 `49c73a15343cdf58edc02328aa27c1d9d4304d919befec1369af26be2ec8fe75`). UnityPy reads the bundle's `Dialogs Shared Data` MonoBehaviour (path ID is recorded in the JSON), its `SharedTableEntry`/`MetadataCollection` data, and managed-reference records typed `LineMetadata` in namespace `Yarn.Unity.UnityLocalization`, assembly `YarnSpinner.Unity`. The compiled graph used for validation is `reconstruction/narrative/program.json`.
